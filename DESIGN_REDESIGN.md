# S.A.T Solution — Premium Website Redesign

This version keeps the existing React/Vite architecture and SEO work, but redesigns the visual system around a premium dark technology aesthetic inspired by the clarity, proof-first structure, and conversion flow of the reference website.

## Design direction
- Dark premium interface with electric-blue accents
- Large editorial typography and short, outcome-focused copy
- Glassmorphism used sparingly for navigation and dashboard UI
- Strong hero CTA hierarchy
- Product/dashboard-style visual instead of a decorative logo-only hero
- Proof/stat strip without inventing business claims
- Service cards with clear individual routes
- Selected work / case-study presentation
- Six-step process presented as a conversion section
- Strong final CTA with secondary pricing route
- Mobile-first navigation and responsive layouts

## Important
The reference site was used for structural inspiration only. No proprietary copy, branding, testimonials, claims, or visual assets were copied.

## Before production
Run:

```bash
npm ci
npm run build
```

Then deploy and verify all routes, especially the prerendered SEO pages.
